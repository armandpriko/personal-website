# 📜 Certificats PDF

## 📁 Structure des fichiers

Placez vos certificats PDF dans ce dossier avec les noms suivants :

### Certificats Zindi :
- `zindi-location-recognition-certificate.pdf` - Certificat Microsoft Learn Location Mention Recognition
- `zindi-fiber-optics-certificate.pdf` - Certificat Togo Fiber Optics Uptake Prediction

### Autres certificats :
- `drone-certificate.pdf` - Certificat de télépilote de drone (A1/A2/A3)
- `conservation-certificate.pdf` - Certificat en conservation des aires protégées

## 🔒 Sécurité

Les PDFs sont affichés avec les protections suivantes :
- ✅ **Pas de téléchargement** direct
- ✅ **Pas d'impression** via le navigateur
- ✅ **Clic droit désactivé**
- ✅ **Raccourcis clavier bloqués** (Ctrl+S, Ctrl+P, etc.)
- ✅ **Sélection de texte désactivée**

## 📱 Compatibilité

- ✅ **Desktop** : Visionneuse PDF intégrée
- ✅ **Mobile** : Affichage optimisé
- ✅ **Tablette** : Interface adaptative

## 🎯 Utilisation

1. **Placez vos PDFs** dans ce dossier
2. **Nommez-les** selon la convention ci-dessus
3. **Les boutons "Voir le certificat"** apparaîtront automatiquement
4. **Clic sur le bouton** → Visionneuse sécurisée s'ouvre

## ⚠️ Important

- Les PDFs doivent être **optimisés** pour le web (< 5MB recommandé)
- **Format A4** recommandé pour un affichage optimal
- **Résolution** : 300 DPI maximum pour éviter des fichiers trop lourds

---

**Vos certificats seront affichés de manière professionnelle et sécurisée !** 🏆
