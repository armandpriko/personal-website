## 📐 Spécifications recommandées

- **Format** : PNG ou JPG
- **Résolution** : 1920x1080 ou plus
- **Taille** : < 2MB par image
- **Qualité** : Haute résolution pour un affichage professionnel
- **Aspect ratio** : 4:3 ou 16:9 recommandé

## 🎯 Utilisation

Ces images seront automatiquement intégrées dans la page **Certifications** avec :
- ✅ **Boutons "Voir l'image"** pour chaque certificat
- ✅ **Visionneuse d'images** sécurisée
- ✅ **Protection contre le téléchargement**
- ✅ **Affichage haute qualité**
