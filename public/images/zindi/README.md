### Projets Zindi :

- `location-recognition-report.png` - Rapport analytique Location Recognition

## 🎯 Utilisation

Ces images seront automatiquement intégrées dans :
- **Page Projets** : Tableaux de bord et rapports
- **Page Certifications** : Certificats visuels
- **Page Réalisations** : Portfolio de projets

## 📐 Spécifications recommandées

- **Format** : PNG
- **Résolution** : 1920x1080 ou plus
- **Taille** : < 2MB par image
- **Qualité** : Haute résolution pour un affichage professionnel
