# 🏆 Images Réalisations & Publications

## 📁 Structure des fichiers

Placez vos images de réalisations dans ce dossier :

### Publications :
- `togo-farmers-study.png` - Image de l'étude sur les agriculteurs du Togo
- `soil-health-analysis.png` - Image de l'analyse de santé des sols

### Dashboards :
- `fapbm-dashboard.png` - Dashboard de suivi des aires protégées FAPBM
- `soil-dashboard.png` - Dashboard d'analyse des sols UniLaSalle

### Rapports Analytiques :
- `congo-deforestation-report.png` - Rapport d'analyse de déforestation Bassin du Congo
- `soil-modeling-report.png` - Rapport de modélisation des sols

### Récompenses & Certifications :
- `major-promotion.png` - Image du diplôme de major de promotion
- `ambassador.png` - Image de la certification ambassadeur

### Challenges :
- `location-recognition-challenge.png` - Image du challenge Microsoft Location Recognition
- `fiber-optics-challenge.png` - Image du challenge Togo Fiber Optics

## 📐 Spécifications recommandées

- **Format** : PNG ou JPG
- **Résolution** : 1920x1080 ou plus
- **Taille** : < 2MB par image
- **Qualité** : Haute résolution pour un affichage professionnel
- **Aspect ratio** : 16:9 recommandé pour les dashboards

## 🎯 Utilisation

Ces images seront automatiquement intégrées dans la page **Réalisations & Publications** avec :
- ✅ **Filtres par catégorie** (Publications, Dashboards, Rapports, Récompenses)
- ✅ **Pagination** pour une navigation facile
- ✅ **Animations** et effets hover
- ✅ **Design responsive** pour tous les écrans
