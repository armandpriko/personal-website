# Images de Projets

Ce dossier contient les images et captures d'écran des projets.

## Structure recommandée :

- `cdt-preview.jpg` - Community Deforestation Tracker
- `soil-analysis-preview.jpg` - Soil Health Analysis
- `spectroscopy-preview.jpg` - Soil Spectroscopy & Predictive Modeling
- `nexus-preview.jpg` - Nexus Observatory Data Platform

## Format recommandé :
- Dimensions : 800x600px minimum
- Format : JPG ou PNG
- Poids : < 500KB par image
- Nommage : kebab-case (ex: mon-projet-preview.jpg)
