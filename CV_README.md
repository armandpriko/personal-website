# CV - Dzudzogbe Prince Armand Koumi

## Instructions pour ajouter votre CV

1. **Nom du fichier** : Renommez votre fichier CV en `cv-dzudzogbe-prince-armand-koumi.pdf`
2. **Placement** : Placez le fichier dans le dossier `public/`
3. **Format** : PDF uniquement (recommandé pour la compatibilité)
4. **Taille** : Maximum 5MB pour un téléchargement rapide

## Structure recommandée du CV

Votre CV devrait inclure :
- Informations de contact
- Résumé professionnel
- Expérience professionnelle (chronologique)
- Formation
- Compétences techniques
- Projets notables
- Certifications
- Publications (si applicable)
- Langues

## Mise à jour automatique

Une fois le fichier ajouté, le lien de téléchargement sera automatiquement fonctionnel sur votre site web.
